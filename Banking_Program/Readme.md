# Banking Program

A simple Java console-based banking application.

## Features
- Check account balance
- Deposit money
- Withdraw money
- Exit banking system

## Concepts Used
- OOP Concepts
- Methods
- Loops
- Switch Case
- User Input using Scanner

## Technologies
- Java

## How to Run
1. Open project in IntelliJ IDEA or Eclipse
2. Run `BankingProgram.java`
