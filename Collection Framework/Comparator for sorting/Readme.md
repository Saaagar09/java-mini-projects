📘 Comparator Demo in Java

This project demonstrates how to use the Comparator interface in Java to sort a list of custom objects (Student) based on specific attributes.

🚀 Features
Create a custom Student class with attributes:
Name
Age
Marks
Store multiple student objects in an ArrayList
Sort students using Comparator
Demonstrates sorting by marks (ascending order)
