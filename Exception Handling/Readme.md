# ⚠️ Java Exception Handling Demo

A simple Java program demonstrating **exception handling** using `try`, `catch`, and `finally`.

---

## 📌 Overview

This project demonstrates how to safely handle runtime errors in Java while performing a basic division operation.

The program:
- Accepts user input
- Performs division
- Handles invalid inputs and errors
- Continues execution until valid input is provided

---

## 🚀 Features

- Handles invalid input (`InputMismatchException`)
- Prevents division by zero (`ArithmeticException`)
- Uses `finally` block (always executes)
- Runs in a loop until correct input is entered

---

## 🧠 Concepts Used

- Exception Handling (`try-catch-finally`)
- Java `Scanner` class
- Looping (`while(true)`)
- Input validation
