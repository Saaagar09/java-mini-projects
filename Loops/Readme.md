Loops in Java 🚀

A beginner-friendly Java program that demonstrates the use of different types of loops and basic programming concepts such as:

While Loop
Do-While Loop
For Loop
Multiplication Table Generator
Sum of N Numbers
Even/Odd Check
Factorial Finder
📌 Features
1. While Loop

Keeps asking for the user's name until a valid input is entered.

2. Do-While Loop

Runs at least once and keeps asking for age until a valid age is entered.

3. For Loop Countdown

Prints numbers from 10 to 1.

4. Print Numbers 1–100

Displays numbers from 1 to 100.

5. Multiplication Table Generator

Generates the multiplication table for any number entered by the user.

6. Sum of N Numbers

Calculates the sum from 0 to N and checks whether the sum is even or odd.

7. Factorial Finder

Calculates the factorial of a given number.
