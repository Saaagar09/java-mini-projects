# Number Guessing Game

A Java console game where the user guesses a randomly generated number.

## Features
- Random number generation
- Tracks number of attempts
- Hint system (High/Low)

## Concepts Used
- Loops
- Random Class
- Scanner Class
- Conditional Statements

## Technologies
- Java

## How to Run
1. Open project in IDE
2. Run `NumberGuessingGameUsingDoWhile.java`
