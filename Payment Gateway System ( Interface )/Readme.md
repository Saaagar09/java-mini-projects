# Java Payment Gateway System

A simple Java project demonstrating the use of Interfaces and Polymorphism.

## Files

- `Payment.java` → Interface
- `PayPal.java` → PayPal payment method
- `Upi.java` → UPI payment method
- `CreditCard.java` → Credit Card payment method
- `Main.java` → Main execution file

## Concepts Used

- Interface
- Implements
- Method Overriding
- Polymorphism
- OOP in Java

## Run

```bash
javac *.java
java Main
```

## Output

```text
Paid 700.0 using PayPal
Paid 900.0 using Upi
Paid 200.0 using Credit Card
```
