# Java Inheritance Example

A simple Java project demonstrating inheritance using `person` and `student` classes.

## Files

- `person.java` → Parent class
- `student.java` → Child class extending `person`
- `inheritence.java` → Main class

## Output

```text
Your name is Sagar And You are 20 Years Old
Your name is Pala And You are 27 Years Old
Pala Gpa is: 7.9
```

## Concepts Used

- Classes & Objects
- Constructors
- Inheritance
- `extends`
- `super()`
